# ภาพสถานที่ท่องเที่ยว สำหรับหน้าแรกแอปจดมิเตอร์ประปา

แอปดึงไฟล์ `places.json` จากที่นี่ทุก 6 ชั่วโมง และทุกครั้งที่ซิงค์ (เมื่อมีเน็ต) แล้วเก็บภาพไว้ในเครื่อง
ไม่มีเน็ตก็ยังเห็นชุดเดิม

## ตั้งค่าครั้งแรก
1. สร้าง repository ชื่อ `water-places` (Public) บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที เปิด `https://thepost10913.github.io/water-places/places.json` ต้องเห็นข้อความ JSON
4. แอปตั้งที่อยู่นี้ไว้แล้ว (`app/build.gradle.kts` บรรทัด `PLACES_URL`)

## เพิ่ม/เปลี่ยนภาพ
1. อัปโหลดภาพเข้าโฟลเดอร์ `images/` (แนวนอน 16:9 กว้าง 1280 px ไม่เกิน 300 KB)
2. เพิ่มรายการใน `places.json` (สูงสุด 12 ภาพ)

| ช่อง | ความหมาย |
|---|---|
| title | ชื่อสถานที่ (ไม่เกิน 60 ตัวอักษร) |
| subtitle | คำโปรย / ที่ตั้ง 1 บรรทัด |
| image | ที่อยู่ภาพ เช่น `images/wat.jpg` |
| link | ลิงก์ Google Maps หรือเพจ (https เท่านั้น เว้นว่างได้) แตะภาพแล้วเปิด |
| credit | เครดิตภาพ (ใช้ภาพที่ถ่ายเองหรือได้รับอนุญาต) |

ระวัง: ไฟล์ JSON ต้องมีจุลภาค `,` คั่นระหว่างรายการ และไม่มีจุลภาคหลังรายการสุดท้าย
ตรวจได้ที่ jsonlint.com ก่อนอัปโหลด

## ความปลอดภัย
- แอปอ่านแค่ข้อความกับภาพ ไม่รันโค้ดใดๆ จากที่นี่
- เปิดยืนยันตัวตน 2 ชั้น (2FA) ให้บัญชี GitHub
- ห้ามใส่ข้อมูลผู้ใช้น้ำในที่นี่ (repository เป็นสาธารณะ)
